# Fixture provenance

All 12 fixtures in this directory are **procedurally generated**, not photographs — generated by
[`tools/gen_fixtures.py`](../../../tools/gen_fixtures.py) from seeded `numpy` RNGs (vertical colour
gradient + a handful of random shapes), then given a per-fixture tonal/format treatment. Re-running
the script reproduces byte-identical files (verified).

**License:** own work, CC0 (public domain) — avoids any third-party photo licensing/provenance
question for a committed test asset. The Adobe RGB ICC profile embedded in `adobergb_tagged.jpg` is
a hand-built minimal profile using publicly published Adobe RGB (1998) colorimetric constants (see
[`tools/_icc.py`](../../../tools/_icc.py)); it is not a copy of Adobe's own profile file.

All images are 480×360 (longest edge 480 ≤ 512 per PLAN.md P0.3).

| File | Covers | Notes |
|---|---|---|
| `neutral.png` | Neutral scene | Balanced grey gradient background |
| `warm_cast.jpg` | Warm cast | R channel boosted, B channel reduced |
| `cool_cast.jpg` | Cool cast | B channel boosted, R channel reduced |
| `dominant_colour.png` | Dominant-colour scene | Green-dominated ("foliage"), low gray-pixel fraction |
| `low_key.png` | Low-key | Overall brightness scaled to ~22% |
| `high_key.png` | High-key | Overall brightness lifted toward white |
| `low_dynamic_range.png` | Low dynamic range | Values compressed into [100, 160] |
| `high_dynamic_range.png` | High dynamic range | Hard-clipped black and white bands added |
| `sixteen_bit.png` | 16-bit PNG | True 16-bit depth (`cv2.IMREAD_ANYDEPTH` reads `uint16`) |
| `exif_rotated.jpg` | EXIF-rotated JPEG | EXIF `Orientation` tag = 6; distinct bright band marks the stored "top" |
| `adobergb_tagged.jpg` | AdobeRGB-tagged JPEG | Embedded ICC profile, non-sRGB primaries + gamma ≈ 2.2 |
| `sample.webp` | WebP | Lossy WebP via OpenCV's WebP encoder |

`tests/golden/expected/` (generated separately by `tools/gen_golden.py`, PLAN.md P0.2) holds the
legacy-pipeline outputs for these fixtures and is not part of this provenance note.
